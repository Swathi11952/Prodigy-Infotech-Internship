# Prodigy Infotech Internship

A collection of web development projects completed as part of my internship at Prodigy Infotech.

This repository contains five front-end projects developed using HTML, CSS, and JavaScript. Each project focuses on different concepts such as responsive design, DOM manipulation, JavaScript functionality, user interaction, and API integration.

---

## Projects

### 1. Responsive Landing Page

A responsive landing page with a fixed navigation bar and multiple sections including Home, About, Services, and Contact.

**Features:**
- Responsive navigation menu
- Scroll-based navigation bar styling
- Hover effects
- Contact form
- Mobile-friendly layout

**Technologies:** HTML, CSS, JavaScript

---

### 2. Stopwatch Web Application

A functional stopwatch application that allows users to measure time with start, pause, reset, and lap features.

**Features:**
- Start stopwatch
- Pause stopwatch
- Reset timer
- Record lap times
- Real-time time display

**Technologies:** HTML, CSS, JavaScript

---

### 3. Tic Tac Toe Game

An interactive two-player Tic Tac Toe game developed using JavaScript.

**Features:**
- Two-player gameplay
- Automatic winner detection
- Draw detection
- Restart game option
- Interactive game board

**Technologies:** HTML, CSS, JavaScript

---

### 4. Personal Portfolio Website

A personal portfolio website designed to showcase skills, projects, education, and professional experience.

**Sections:**
- Home
- About Me
- Skills
- Projects
- Contact

**Technologies:** HTML, CSS, JavaScript

---

### 5. Weather Application

A web-based weather application that allows users to search for a city and view its current weather information.

**Features:**
- City-based weather search
- Temperature display
- Weather condition
- Humidity information
- Wind speed
- Error handling for invalid cities

**Technologies:** HTML, CSS, JavaScript, OpenWeatherMap API
